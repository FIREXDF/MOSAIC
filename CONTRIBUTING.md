# Contributing to MOSAIC

Thanks for wanting to contribute to MOSAIC!

## Branches

* `main` — latest stable version
* `develop` — current development
* `feature/*` — new features
* `fix/*` — bug fixes
* `release/*` — release preparation
* `hotfix/*` — urgent fixes

## Development

Create a branch from `develop` for your changes.

For example:

```text
feature/add-mod-manager
fix/download-error
```

When your changes are ready, open a Pull Request to `develop`.

## Commits

There is no strict commit format.

Keep commits short and descriptive:

```text
add mod manager
fix download bugs
update UI
remove old code
update dependencies
```

## Releases

Releases go through:

**Alpha → Beta → Stable**

Stable releases are merged into `main` and published as version tags.

## Pull Requests

Make sure your changes are tested before opening a Pull Request.

Keep Pull Requests focused and explain what you changed when necessary.

## AI Policy

AI tools are allowed and can be used to help with development.

If AI was used to generate, modify, or significantly assist with code, this should be clearly stated in the Pull Request.

All AI-assisted code must be reviewed by a human before being submitted. Contributors are responsible for understanding, testing, and verifying the code they submit.

AI-generated code should not be submitted without human review.
