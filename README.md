# A mod manager for SSBU
[![MOSAIC Use](https://skillicons.dev/icons?i=electron,html,css,ts)](https://skillicons.dev)

## MOSAIC is a mod manager for SSBU that make modding easier.

- Disable/Enable mods
- Uninstall mods
- 1-Click Install on GameBanana
- Manage Plugins
- Launch emulator throught MOSAIC
- CSS Editor
- See image/info of the mod
- Rename mods
- Change Character slots
------------------------------------------------

# Build MOSAIC.

Clone the repository

And run those command
`npm install`
`npm run build`
